🃏 Le Grand Réseau Social : Copier pour Exister

Ce projet analyse une société devenue un jeu de cartes géant où l'identité est dictée par l'influence américaine.

    L'Uniformisation : Tout est calqué sur les USA (sport, langue, look). La musique pop est devenue l'unique code pour exprimer ses émotions.

    Les Profils "Cartes" : Sur les réseaux, chacun joue un rôle prédéfini :

        La Dame : Celle qui ignore volontairement la réalité.

        Le Roi : Celui qui observe et analyse tout.

        Les Numéros : Les pions qui restent discrets et suivent le mouvement.

    La Course aux Stars : Une compétition permanente sur les médias sociaux pour ressembler aux idoles musicales et ne jamais perdre la face.

En bref : Une critique de notre monde où l'on ne vit plus, mais où l'on s'aligne sur des modèles comme des figures sur une partition ou des pions sur un plateau.
